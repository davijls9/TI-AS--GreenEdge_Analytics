
2.1 Lista de Atores
Os atores deste projeto, considerando a abordagem do Design Thinking, envolvem:

1. Gestor de TI: Necessita de relatórios detalhados sobre o consumo de energia e eficiência para tomadas de decisões.
2. Analista de Dados: Utiliza o dashboard para analisar o comportamento dos servidores e identificar padrões de uso.
3. Diretoria Executiva: Requer uma visão simplificada dos indicadores-chave de desempenho (KPIs) para decisões estratégicas.
4. Engenheiro de Sustentabilidade: Busca dados de eficiência energética e sustentabilidade para elaborar relatórios de impacto ambiental.
5. Operador de Servidores: Monitora as métricas em tempo real para assegurar o funcionamento adequado dos sistemas.

2.2 Lista de Funcionalidades
Funcionalidades a serem atendidas no projeto na visão do cliente:

- Visualizar métricas de eficiência energética, como PUE, DCiE, CUE, e WUE.
- Monitorar uptime dos servidores com histórico de falhas.
- Gerar relatórios personalizados sobre consumo de energia e desempenho de servidores.
- Visualizar a eficiência dos ventiladores e impacto na eficiência geral do data center.
- Exportar gráficos e relatórios para apresentações e reuniões.

2.6 Restrições Arquiteturais
- Ferramenta de Visualização e Análise de Dados: O dashboard deverá ser desenvolvido utilizando Power BI como a principal ferramenta de visualização de dados, permitindo a criação de gráficos interativos e relatórios detalhados sobre o consumo de energia da Justweb.
- Linguagem de Design e Implementação: A implementação do front-end e back-end será realizada utilizando DAX (Data Analysis Expressions), que servirá como base para o design e a lógica de cálculos no Power BI.
Persistência de Dados: A persistência dos dados deverá ser gerenciada por meio de ORM (Object-Relational Mapping), facilitando a integração dos dados com o Power BI e garantindo a consistência e acessibilidade das informações armazenadas.
- Integração com Sistemas Existentes: O sistema deverá permitir a integração com outras bases de dados ou sistemas de monitoramento energético existentes na Justweb, garantindo que os dados relevantes possam ser importados e visualizados no Power BI sem a necessidade de reestruturar o sistema existente.
- Segurança e Controle de Acesso: A segurança dos dados e o controle de acesso ao dashboard devem ser gerenciados por meio das funcionalidades nativas do Power BI, garantindo que apenas usuários autorizados possam acessar, visualizar ou modificar os dados.
- Métricas de Eficiência Energética: As métricas propostas, como PUE, WUE e CUE, deverão ser implementadas diretamente no Power BI, utilizando DAX para criar medidas e cálculos necessários para a análise de eficiência energética.
